# Erin Wu — Personal Portfolio

A minimal English portfolio for GitHub Pages, based on Erin's CV (10).

## Publish

1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, `.nojekyll`, and the complete `assets/` folder to the **root** of the repository.
3. In GitHub, choose **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save**.
4. Open `https://YOUR-USERNAME.github.io/` after GitHub finishes publishing.

You can first open `index.html` locally in a browser to preview the page.

## Updating

- Change page wording and links in `index.html`.
- Change colors, fonts, and spacing in `styles.css`.
- Replace `assets/Erin_Wu_CV.pdf` whenever the résumé changes.
- The graph in the featured project is **illustrative**, not real financial data.
- The website intentionally has no photo or phone number. The linked CV contains contact details: review whether you want that publicly accessible before publishing.
- Do not upload proprietary bank information or restricted TEJ source data.

No build tools or dependencies are needed.
